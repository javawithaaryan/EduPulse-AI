# EduPulse AI - Quick Start Guide

## 🚀 How to Run
We have simplified the startup process for you. 

1.  **Double-click `start_edupulse.bat`** in this folder.
2.  That's it! 
    -   It will automatically start the backend.
    -   It will open your web browser to `http://localhost:5000`.

## 🛠️ Update & Maintenance
To update the application code:
1.  Edit the files in `src/`.
2.  Open a terminal in `Frontend` and run:
    ```powershell
    npm run build
    ```
3.  Restart `start_edupulse.bat`.

## 🔑 Credentials
Ensure your `backend/.env` file has the correct Azure keys for AI features to work.
